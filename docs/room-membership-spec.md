# ルーム参加解除仕様

## Objective

共有ルームの参加者が、自分の参加状態だけを解除して、ルーム選択画面へ戻れるようにする。ルーム本体や対局データは残し、他の参加者の利用には影響させない。

## Rules

- Googleログインが有効な環境で、現在のルームに紐付く `member` だけが実行できる。
- `owner` は参加解除できない。所有者は「ルームを削除」を使う。
- 参加解除では `room_members` の自分の行だけを削除する。
- 参加解除後も、招待URLを再度開けば招待コードを使って再参加できる。
- Googleログイン無効の旧運用では、参加者の識別情報がないため利用できない。

## API

- `DELETE /api/rooms/:code/membership`
- ログイン必須。対象ルームの `room_members` が `member` であることを確認する。
- owner、未参加、ルーム不存在は404を返し、権限情報を必要以上に開示しない。
- 成功時は `{ "roomCode": "..." }` を返す。

## UI

- 参加者だけ設定画面に「このルームを抜ける」を表示する。
- 確認ダイアログで、対局データは削除されないことを説明する。
- 成功後は現在のルームを離れ、ルーム選択画面へ戻り、ルーム一覧を再取得する。
- 失敗時は設定画面にエラーを表示する。

## Success Criteria

- memberが確認操作を経て自分の参加状態だけを解除できる。
- owner、未認証、未参加ユーザーは解除できない。
- room、games、draft、他ユーザーのroom_membersは削除されない。
- `npm run check` と `npm run build` が成功する。
