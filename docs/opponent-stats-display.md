# 相手別ロン・放銃の表示

- 成績画面で人を選ぶと、相手別集計と局ごとの明細を一緒に切り替える。今日／全期間の条件も両方へ適用する。
- 矢印は「放銃者 → 和了者」。選択者を替えても方向は変えない。
- 基本点・本場・リー棒移動を別の列に表示し、括弧でつなげない。補足や局明細は初期表示から残す。
- 差し引きは基本点のロン合計から放銃合計を引く。本場・供託は含めない。
- リー棒移動は場の供託から和了者へ渡る点数で、放銃者の支払ではない。局明細の受取には含め、支払には含めない。立直宣言時の支出はこの受取・支払と相殺しない。
- ダブロン・トリプルロンは相手ごとに表示し、各和了者の本場と最初の和了者への供託を保持する。相手別放銃回数の和は、局データの放銃局数と一致しない場合がある。
- 保存形式・Worker APIは変更しない。既存の局ログの再生と点数計算を使う。

作業環境の版には公開サイトの相手別機能が含まれていなかったため、独立した集計モジュールと表示パネルとして実装した。公開版の最新ソースとの統合を確認してから本番へ反映する。
