# 成績タブ詳細分析仕様

## Objective

局ログで入力できている和了・放銃・翻符・立直・テンパイ・親の情報を、成績タブでより具体的に振り返れるようにする。既存の合計スコア・順位分布・基本率を残したまま、プレイヤーごとの局データ比較と、半荘ごとのスコア推移を表示する。

## Scope and assumptions

- 既存の `Game` / `Hand` データを利用し、保存形式とWorker APIは変更しない。
- 局ログがある対局だけを局データ分析の対象にする。簡単入力の対局は順位・スコア推移には含めるが、局データの率計算には含めない。
- 「立直後の和了率」は、同じ局で立直宣言後に和了した回数 ÷ 立直宣言回数とする。
- 親和了率は、親として参加した局での和了回数 ÷ 親として参加した局数とする。
- ダブロン・トリプルロンは、和了者ごとの和了として数え、放銃は1回、放銃失点は和了者分を合算する。
- `adjust` は局数・勝率・推移の対局数を歪めるため、局データ分析から除外する。

## User-facing changes

- 局データ表に、ロン／ツモ回数、平均翻、平均符、立直後の和了率、親和了率を追加する。
- 「詳細分析」表で、和了・放銃・立直・親の指標をプレイヤー間で比較できるようにする。
- 「スコア推移」パネルで、表示中の期間における半荘ごとの累計スコアを折れ線で確認できるようにする。
- 今日／全期間の既存フィルターを、新しい表示にも適用する。
- 数値表を併設し、色やグラフだけに依存しない。局ログがない場合は、従来どおり理由と入力方法を案内する。

## Tech Stack and structure

- React 18 + TypeScript + Vite。新しいチャートライブラリは追加しない。
- `src/lib/stats.ts`: 局ログ由来の派生指標とスコア推移を純粋関数で集計する。
- `src/lib/stats.test.ts`: 集計の分母、ダブロン、親子、立直和了、推移をテストする。
- `src/views/StatsView.tsx`: 期間で絞った集計結果を表示パネルへ渡す。
- `src/views/StatsPanels.tsx`: 詳細分析表とSVGグラフの表示だけを担当する。
- `src/styles.css`: 表・グラフのレスポンシブ表示とアクセシビリティを定義する。

## Testing strategy

- `npm run test -- src/lib/stats.test.ts` で、通常の和了・ロン／ツモ・ダブロン・立直和了・親和了・adjust除外・推移を検証する。
- `npm run typecheck` と `npm run lint` で型・Reactフック・アクセシビリティ上の問題を確認する。
- `npm run check` と `npm run build` で既存機能を含む全体を確認する。
- 画面ではデスクトップ幅、390px幅、局ログなし、1対局、複数対局、今日フィルターを確認する。

## Boundaries

- Always: 既存の期間フィルター、後方互換、数値ラベル、純粋関数テストを維持する。
- Ask first: DBスキーマ、Worker API、外部依存、既存の得点定義を変更する場合。
- Never: 既存の集計項目を黙って別の分母へ変更する。局ログのない対局を局データ率へ混ぜる。

## Success criteria

- 局ログのあるプレイヤーについて、詳細分析表で和了・放銃・立直・親の指標を比較できる。
- 半荘ごとの累計スコア推移が、今日／全期間フィルターに応じて更新される。
- グラフには凡例・数値表現・スクリーンリーダー用ラベルがあり、色だけで意味を伝えない。
- 局ログのない既存対局の順位・スコア表示と、既存の基本集計が変わらない。
- `npm run check` と `npm run build` が成功する。
